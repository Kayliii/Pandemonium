# Pandemonium

A wacky and chaotic mod for Balatro.

Requires [Steamodded](https://github.com/Steamodded/smods/releases/latest) to work.

## Features

The following additions are currently available.

- 15 new Jokers
- 1 new Deck
- 2 new Vouchers
- 6 new Planet Cards (+ 2 secret ones)
- 1 new Spectral Card
- 5 Teuila Cards
- 1 new Seal
- 1 new Tag
- 10 new Blinds
- 1 new Sticker
- 6 new Poker Hands (+ 2 secret ones)
- 4 new Challenges

It also changes a few mechanics that will affect vanilla Jokers; in particular, expect Four Fingers to be affected.

## Disclaimer

This is an early and unstable version of Pandemonium. You may experience crashes, you *will* experience bugs, and a lot of planned content is not yet implemented.

If you run into any bugs, please report them on Github's issue tracker.
